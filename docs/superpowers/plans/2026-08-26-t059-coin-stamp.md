# T-059 Coin Stamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the coin's flat yellow `CircleGeometry` with a stamped paper disc — rim, face and centre stamp merged into one vertex-coloured `BufferGeometry` — without changing gameplay.

**Architecture:** Three **coplanar, non-overlapping** annuli tile the disc exactly: a `RingGeometry` rim, a `RingGeometry` face, and a `CircleGeometry` stamp, each part's inner radius being the previous part's outer radius. Flat-fill each with a vertex colour, `mergeGeometries` them into ONE `BufferGeometry`, draw with ONE white `MeshLambertMaterial({ vertexColors: true, side: DoubleSide })`. Zero overlap means zero z-fighting and zero Z offsets — the disc stays exactly paper-thin, so the existing Y-spin still reads edge-on twice a revolution.

**Tech Stack:** TypeScript, three.js 0.180 (`RingGeometry`, `CircleGeometry`, `mergeGeometries` from `three/addons/utils/BufferGeometryUtils.js`), vitest.

**Spec:** `/home/box/.claude/plans/brainstorming-you-are-executing-synthetic-dahl.md` (T-059 approved design)

- Colour assertions compare against `new THREE.Color(hex)` channels, never raw hex — `THREE.Color` runs a hex through the working colour space, so stored vertex values are not the source literals.

- [ ] **Step 1: Write the minimal implementation**

Add, mirroring `src/entities/enemies/walker.ts:66-112`:

```ts
/** Rim and stamp, either side of the established COIN_COLOR face. */
const COIN_RIM_COLOR = 0xc98a12
const COIN_STAMP_COLOR = 0x8a5a08

/** Part radii as fractions of the disc: an 18% rim band, a legible centre mark. */
const COIN_FACE_RATIO = 0.82
const COIN_STAMP_RATIO = 0.28

function paint(geometry: THREE.BufferGeometry, hex: number): void { /* as in walker.ts */ }

function createCoinGeometry(): THREE.BufferGeometry {
  const discRadius = (COIN_WIDTH * TILE_SIZE) / 2
  const faceRadius = discRadius * COIN_FACE_RATIO
  const stampRadius = discRadius * COIN_STAMP_RATIO

  const rim = new THREE.RingGeometry(faceRadius, discRadius, COIN_SEGMENTS)
  paint(rim, COIN_RIM_COLOR)
  const face = new THREE.RingGeometry(stampRadius, faceRadius, COIN_SEGMENTS)
  paint(face, COIN_COLOR)
  const stamp = new THREE.CircleGeometry(stampRadius, COIN_SEGMENTS)
  paint(stamp, COIN_STAMP_COLOR)

  const merged = mergeGeometries([rim, face, stamp])
  if (merged === null) throw new Error('coin: rim, face and stamp attributes are incompatible')

  rim.dispose()
  face.dispose()
  stamp.dispose()
  return merged
}
```

Change the field type to `THREE.Mesh<THREE.BufferGeometry, THREE.MeshLambertMaterial>` and the constructor to `new THREE.Mesh(createCoinGeometry(), new THREE.MeshLambertMaterial({ vertexColors: true, side: THREE.DoubleSide }))`. Update the top-of-file comment to name T-059. **Touch nothing else** — `step`, `collect`, the AABB constants and the position formula stay exactly as they are.
