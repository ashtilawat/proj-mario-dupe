# T-033 Player Art Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the player's default yellow capsule with a hat-and-body character mesh built inside `player.ts`, so the player reads as a character instead of a gray-box stand-in.

**Architecture:** Five `BoxGeometry` parts translated into place, flat-filled with a per-vertex colour attribute, and merged by `mergeGeometries` into ONE `THREE.BufferGeometry` drawn by ONE white `MeshLambertMaterial({ vertexColors: true })`. This mirrors T-030's walker mushroom. The result is a single root `THREE.Mesh`, so `player.ts` step 8's `mesh.scale.set(scaleXZ, scaleY, scaleXZ)` keeps scaling the whole character as one object.

**Tech Stack:** TypeScript, three@0.180 (`three/addons/utils/BufferGeometryUtils.js`), vitest + jsdom.

## Mesh Geometry Table

Centred on the origin: `y ∈ [-0.75, 0.75]`, `|x| ≤ 0.35` — the same silhouette box the capsule filled, so framing and the centre-anchored squash pivot do not shift. Adjacent parts overlap ~0.02 in Y so no seam can open.

| Part      | Colour     | X span        | Y span        | Z depth |
|-----------|------------|---------------|---------------|---------|
| Shoes     | `0x4a2f1b` | -0.20 … 0.35  | -0.75 … -0.59 | 0.44    |
| Overalls  | `0x2e5bbf` | -0.26 … 0.26  | -0.62 … -0.05 | 0.40    |
| Head      | `0xe8c547` | -0.23 … 0.23  | -0.07 …  0.35 | 0.42    |
| Hat brim  | `0xe0392b` | -0.24 … 0.35  |  0.33 …  0.45 | 0.50    |
| Hat crown | `0xe0392b` | -0.21 … 0.21  |  0.43 …  0.75 | 0.40    |

Five boxes, FOUR distinct colours — crown and brim share the hat red, so colour-partitioning yields four parts.

Two deliberate readability choices:
1. The brim (half-width 0.35) overhangs the head (half-width 0.23) — the wide-over-narrow trick that made the mushroom read.
2. Shoes and brim are front-heavy in +X (they reach 0.35 forward but only -0.20/-0.24 back). The capsule was rotationally symmetric about Y, so the `TURN_RATE` lerp on `mesh.rotation.y` was invisible; giving the character a front makes that existing animation show.

- [ ] **Step 1: Write the failing tests**

Create `tests/player-art.test.ts` with the ten cases below. Reuse T-030's harness idea: partition geometry vertices by vertex colour into parts carrying `minY`/`maxY`/`minX`/`maxX`/`halfWidth`, sorted topmost first.

1. `is one Mesh with a single Lambert material and no geometry groups` — `instanceof THREE.Mesh`, `children` empty, `Array.isArray(material) === false`, `MeshLambertMaterial`, `vertexColors === true`, `material.color.getHex() === 0xffffff` (Lambert multiplies material colour by vertex colour, so any tint darkens every part), `geometry.groups` empty.
2. `carries a per-vertex colour attribute` — present, `itemSize === 3`, `count` equals the position count.
3. `is not the yellow capsule` — `geometry` is not a `CapsuleGeometry`, and the mesh has four distinct vertex colours rather than one flat `0xe8c547`.
4. `sits inside the player hitbox` — bounding-box height `≈ 1.5`, width `≤ 0.7`, centred on the origin so the feet land on `aabb.y` once `step()` places it.
5. `reads as a character: the hat brim overhangs the head` — the topmost part's half-width exceeds the head's; shoes are the bottom part.
6. `overlaps at every join, so no seam can open` — each adjacent pair's Y spans intersect.
7. `has a front, so the facing turn is visible` — hat and shoes reach further in +X than -X.
8. `keeps the T-026 squash and stretch on the default mesh` — build a player with NO injected mesh, jump, assert `scale.y > 1`, `scale.x === 1/sqrt(scale.y)`, `scale.z === scale.x`; then land and assert recovery to a bit-exact identity scale. THIS is the load-bearing test: it proves the new mesh is still one root object that scales as a whole.
9. `never resizes the hitbox` — `PLAYER_WIDTH`/`PLAYER_HEIGHT` still `0.7`/`1.5`, and `body.aabb.w`/`.h` are unchanged after create AND after squash/stretch frames.
10. `honours an injected mesh` — `createPlayer({ mesh: stub })` returns that exact object.
